Generation Check is a tool built using Python in Visual Studio Code that tells the user what generation they belong to upon entering (their/a) birth year.

Features:

Submit button and text box to enter birth year (or any year for curiosity)
Labels that display what generation the inputted birth year is in

IMPORTANT:
This program is only known to run in windows thus far. If you run it in macOS or Linux there's a chance it may not work.

This is the first release of Generation Check. Bug reports and feedback are welcome via the Issues tab.
